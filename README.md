# 智慧大学 · 高考志愿决策参考工具

基于教育部公开数据（2,756 所院校 · 860 个本科专业），支持上传任意省份录取数据，提供四种维度的志愿决策参考。

## 功能

| 模式 | 说明 |
|------|------|
| 01 地域 → 学校 → 专业 | 按省份/城市/等级/类型筛选院校，展开查看开设专业与优势专业 |
| 02 专业 → 地域 → 学校 | 选定专业后反查全国开设院校，支持按省份/等级/优势二次筛选 |
| 03 录取数据 · 分数推荐 | 上传本省录取 JSON 后，按分数/位次生成冲/稳/保三档96志愿推荐 |
| 04 大学专业顾问 | 接入任意 OpenAI 兼容 AI 大模型，内置高考志愿专家系统提示词 |

## 快速启动

```bash
# 在项目目录下启动本地服务器
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

> 不能直接双击 `index.html` 打开，浏览器会拦截 `fetch` 请求。

## 模式三：如何上传你所在省份的数据

模式三支持任意省份，数据需由你自行准备并处理。

### 所需原始数据

- 历年**招生计划**（Excel，含院校、专业、计划人数、学费、选科要求等）
- 历年**专业录取分数**（最低分、最低位次）
- 历年**院校录取分数**（最低分、最低位次）
- 历年**一分一段表**（分数 → 累计人数）

数据来源：各省招生考试信息网（公开数据）

### 生成 JSON

参照 `scripts/parse_qinghai_history.py` 修改字段映射，生成符合以下格式的 JSON 文件：

```json
{
  "plans": [...],        // 招生计划数组
  "majorScores": [...],  // 专业录取分数数组
  "schoolScores": [...], // 院校录取分数数组
  "rankTable": [...],    // 一分一段表 [{score, cum}]
  "_meta": { "plans": 数量, "majorScores": 数量 }
}
```

### 上传使用

在模式三页面将 JSON 文件拖入上传区（文件名需包含4位数字年份，如 `2024.json`），支持同时上传多个年份。上传后分数推荐、院校趋势、招生计划三个子功能自动启用。

## 模式四：大学专业顾问

在模式四左侧填入 API Base URL、API Key 和模型名称，点击"保存配置并连接"即可开始对话。

- 支持任意兼容 OpenAI API 格式的服务（OpenAI、Claude、DeepSeek、Qwen 等）
- 系统提示词已内置固定，无需用户设置，确保专业性
- API Key 仅存于本地浏览器，不会上传至任何服务器

## 数据来源

- 教育部《全国普通高等学校名单》(2021)
- 《普通高等学校本科专业目录》(2026)
- 985 / 211 / 双一流官方公示名单
- 用户自行上传的省份录取数据与一分一段表

## 注意

- "开设专业""优势专业"为基于学校类型的启发式推断，非官方数据
- 分数推荐基于历年位次比例，仅供参考
- 最终请以学校招生章程与省教育考试院公告为准
- 本工具不替代专业志愿填报咨询
